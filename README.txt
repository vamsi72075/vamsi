VAMSI PORTFOLIO
================

Files:
- index.html  -> website structure
- style.css   -> responsive design and colors
- script.js   -> mobile menu and contact form behavior

Open index.html in a browser to view the portfolio.

To use your own photo:
1. Add your image to this folder, for example profile.jpg.
2. Replace the avatar <div> in index.html with:
   <img src="profile.jpg" alt="Vamsi">

The contact form is front-end only. To receive real messages, connect it to a backend or form service.
